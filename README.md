
# Proyecto React

Este proyecto está desarrollado con **React** y utiliza un servidor local para gestionar los datos. A continuación, encontrarás las instrucciones para ejecutar el proyecto en un entorno de desarrollo.

## Características

- **Framework:** React  
- **Servidor:** Node.js con datos almacenados en un archivo `db.json`.  
- **Scripts de desarrollo:**  
  - `npm start` para ejecutar el cliente.
  - `npm run server` para iniciar el servidor local.

## Requisitos previos

Antes de comenzar, asegúrate de tener instalados los siguientes programas:

- [Node.js](https://nodejs.org) (versión 14 o superior)
- [npm](https://www.npmjs.com/) (normalmente incluido con Node.js)
